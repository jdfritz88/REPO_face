# REPO_face

## Purpose

This repo exists to build **"Face N the Crowd"**: an app that searches photos and videos for
faces, to gather face images for training face LoRAs.

## Intent

The app will be released to the public, either for a fee or for donations.

## Licenses

Every underlying system (libraries, models, model weights, datasets, tools) has a license, and
those licenses must be weighed in every design decision. Because the app may be sold or take
donations, check each license for:

- whether commercial use is allowed;
- whether it requires the app's own code to be released under the same license (for example
  GPL or AGPL);
- attribution or notice requirements;
- separate licenses on model weights or training data, which can differ from the code's license.
